When the technician clicks "View Details" on a task card…

How should the task details be shown?

A

Side drawer / slide-over panel

A panel slides in from the right, showing task details without leaving the list page. The technician can close it and go back to the card list instantly.

  • Fast to open/close
  • List stays visible behind the panel
  • Good for quick reference
B

Dedicated detail page

Navigates to /technician/planning-tasks/:taskId — a full page showing all task information with a Back button to return to the list.

  • More space for information
  • "Demander une intervention" button lives here too
  • Shareable URL
C

Modal dialog

A centered overlay dialog opens on top of the list. Both the details and the "Demander une intervention" button are inside the modal.

  • No navigation needed
  • Same pattern as other dialogs in the app
  • Less space than a full page
