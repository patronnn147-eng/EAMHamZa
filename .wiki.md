# Project Summary
The Asset Management System is a sophisticated web application designed to optimize the management of industrial assets, work orders, and maintenance schedules. It enhances operational efficiency for businesses by providing tools for user management, machine tracking, and work order processing, ultimately streamlining asset management processes.

# Project Module Description
- **User Management**: Handles user roles, authentication, and password management using JWT-based authentication.
- **Machine Management**: Manages machine details, statuses, and maintenance schedules.
- **Work Orders**: Allows for the creation, editing, and tracking of work orders related to machines.
- **Planning**: Aids in scheduling and planning maintenance and work orders.
- **Interventions**: Tracks and documents maintenance interventions with complete CRUD functionality.
- **Reports**: Generates and manages operational and maintenance reports.
- **Dashboard**: Displays an overview of key metrics and statuses across the system.
- **Technician Interface**: Provides a dedicated interface for technicians with role-specific capabilities.
- **Authentication**: Updated to support JWT-based authentication.

# File Description Inventory
- **backend/**: Contains all backend logic, including models, routes, services, and authentication.
- **frontend/**: Contains all frontend files, including React components, styles, and public assets.
- **README.md**: Documentation for project setup and usage.
- **requirements.txt**: Lists dependencies for backend and frontend, including bcrypt for password hashing.
- **JWT_AUTHENTICATION_MIGRATION.md**: Documentation summarizing the migration from OIDC to JWT authentication.
- **auth.py**: Contains updated authentication logic for handling user authentication and authorization.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Tailwind CSS, Shadcn-ui
- **Database**: PostgreSQL
- **Authentication**: JWT-based authentication using passlib for password hashing

# Usage
1. **Install Dependencies**:
   - For the backend, navigate to the `/backend` directory and run `pip install -r requirements.txt`.
   - For the frontend, navigate to the `/frontend` directory and run `pnpm install`.
   
2. **Build**: 
   - For the frontend, run `pnpm run build` to create a production build.
   
3. **Run**:
   - Start the backend service by executing `uvicorn main:app --reload` in the backend directory.
   - Start the frontend development server by running `pnpm run dev` in the frontend directory.
