# Project Summary
The Asset Management System is a comprehensive web application designed to manage industrial assets, work orders, and maintenance schedules. It facilitates user management, machine tracking, work order processing, planning, archiving, and reporting. Built with a modern tech stack, it aims to enhance operational efficiency and streamline asset management processes.

# Project Module Description
- **User Management**: Handles user roles, authentication, and password management.
- **Machine Management**: Manages machine details, statuses, and maintenance schedules.
- **Work Orders**: Facilitates creation, editing, and tracking of work orders linked to machines.
- **Planning**: Supports scheduling and planning of maintenance and work orders.
- **Archives**: Manages archived documents and files related to work orders and maintenance.
- **Reports**: Generates and displays operational and maintenance reports.
- **Dashboard**: Provides an overview of key metrics and statuses across the system.

# File Description Inventory
- **backend/**: Contains all backend logic, including models, routes, and services for handling data and business logic.
- **frontend/**: Contains all frontend files including React components, styles, and public assets.
- **README.md**: Documentation for project setup and usage.
- **requirements.txt**: Lists dependencies for backend and frontend.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Tailwind CSS, Shadcn-ui
- **Database**: PostgreSQL
- **Authentication**: Atoms Backend for user management and authentication

# Usage
1. **Install Dependencies**:
   - For the backend, navigate to the `/backend` directory and run `pip install -r requirements.txt`.
   - For the frontend, navigate to the `/frontend` directory and run `pnpm install`.
   
2. **Build**: 
   - For the frontend, run `pnpm run build` to create a production build.
   
3. **Run**:
   - Start the backend service by executing `uvicorn main:app --reload` in the backend directory.
   - Start the frontend development server by running `pnpm run dev` in the frontend directory.
