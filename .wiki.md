# Project Summary
The Asset Management System is a web application focused on industrial asset management, aimed at optimizing work orders and maintenance schedules. It enhances operational efficiency through features such as user management, machine tracking, and work order processing. Recent updates have significantly improved the planning module, introducing new functionalities for scheduling and user roles.

# Project Module Description
- **User Management**: Handles user roles, authentication, and password management via JWT-based authentication.
- **Machine Management**: Manages machine details, statuses, and maintenance schedules.
- **Work Orders**: Enables the creation, editing, and tracking of work orders associated with machines.
- **Planning**: Manages maintenance and shift scheduling; admins can set up planning with specific operations and assigned technicians, while regular users can view planning details only.
- **Interventions**: Logs and tracks maintenance interventions with comprehensive CRUD capabilities.
- **Reports**: Generates and manages operational and maintenance reports.
- **Dashboard**: Provides an overview of key metrics and system statuses.
- **Technician Interface**: Offers a specialized interface for technicians with role-specific functionalities.
- **Settings Management**: Manages application settings.
- **ChefTech Module**: Introduces features for managing ChefTech-specific machines and operations.
- **Chetop Module**: Adds functionalities for Chetop-related tasks and dashboards.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Tailwind CSS, Shadcn-ui
- **Database**: PostgreSQL (default SQLite for development)
- **Authentication**: JWT-based authentication using passlib for password hashing

# Usage
1. **Install Dependencies**:
   - For the backend, navigate to the `/backend` directory and run `pip install -r requirements.txt`.
   - For the frontend, navigate to the `/frontend` directory and run `pnpm install`.
   
2. **Build**: 
   - For the frontend, run `pnpm run build` to create a production build.
   
3. **Run**:
   - Start the backend service by executing `uvicorn main:app --reload` in the backend directory.
   - Start the frontend development server by running `pnpm run dev` in the frontend directory.
