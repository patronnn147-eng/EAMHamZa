# Project Summary
The Asset Management System is a comprehensive web application designed to optimize industrial asset management, focusing on work orders and maintenance schedules. The system enhances operational efficiency by offering features such as user management, machine tracking, and work order processing. Recent improvements have included enhanced user authentication, improved settings management, and password length validation to reduce registration errors.

# Project Module Description
- **User Management**: Manages user roles, authentication, and password handling using JWT-based authentication.
- **Machine Management**: Oversees machine details, statuses, and maintenance schedules.
- **Work Orders**: Facilitates the creation, editing, and tracking of work orders linked to machines.
- **Planning**: Supports scheduling and planning for maintenance and work orders.
- **Interventions**: Logs and tracks maintenance interventions with full CRUD capabilities.
- **Reports**: Generates and manages operational and maintenance reports.
- **Dashboard**: Displays an overview of key metrics and system statuses.
- **Technician Interface**: Provides a specialized interface for technicians with role-specific functionalities.
- **Settings Management**: Handles application settings.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Tailwind CSS, Shadcn-ui
- **Database**: PostgreSQL (default SQLite for development)
- **Authentication**: JWT-based authentication using passlib for password hashing

# Usage
1. **Install Dependencies**:
   - For the backend, navigate to the `/backend` directory and run `pip install -r requirements.txt`.
   - For the frontend, navigate to the `/frontend` directory and run `pnpm install`.
   
2. **Build**: 
   - For the frontend, run `pnpm run build` to create a production build.
   
3. **Run**:
   - Start the backend service by executing `uvicorn main:app --reload` in the backend directory.
   - Start the frontend development server by running `pnpm run dev` in the frontend directory.
