# Project Summary
The project aims to develop an Asset Management software website that facilitates the management of assets through a comprehensive web application. The software will include functionalities such as user authentication, machine management, work order management, maintenance planning, and reporting. While the initial request was to use Spring Boot and Angular, the development will proceed using a technology stack that includes Shadcn-ui, TypeScript, Tailwind CSS, and a backend system to maintain the required functionality as per the class diagram.

# Project Module Description
- **User Authentication**: Manages user roles including CHETOP, TECHNICIEN, CHEFTECH, and ADMIN.
- **Machine Management**: Tracks the status of machines within the system.
- **Work Order Management**: Handles the creation and tracking of work orders (OrdreTravail).
- **Maintenance Planning**: Provides tools for scheduling and tracking maintenance activities.
- **Archive Management**: Manages document storage and retrieval.
- **Reporting Functionality**: Generates reports based on the asset management data.
