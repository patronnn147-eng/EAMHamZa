# Project Summary
The Asset Management System is a web application tailored for industrial asset management, focusing on optimizing work orders and maintenance schedules. Its goal is to enhance operational efficiency through features like user management, machine tracking, and comprehensive work order processing. Recent updates have improved the planning module, now allowing for better scheduling and role management, specifically accommodating maintenance and shift planning.

# Project Module Description
- **User Management**: Handles user roles, authentication, and password management with JWT-based authentication.
- **Machine Management**: Manages machine details, operational statuses, and maintenance schedules.
- **Work Orders**: Facilitates the creation, editing, and tracking of work orders linked to machines.
- **Planning**: Supports maintenance and shift scheduling, with differentiated views for admins and regular users. Admins can create and manage plans, while users can view planning details.
- **Interventions**: Logs and tracks maintenance interventions with full CRUD capabilities.
- **Reports**: Generates operational and maintenance reports.
- **Dashboard**: Provides an overview of critical metrics and system statuses.
- **Technician Interface**: A specialized interface for technicians with role-specific functionalities.
- **Settings Management**: Manages application settings.
- **ChefTech Module**: Manages ChefTech-specific machines and operations.
- **Chetop Module**: Adds functionalities for Chetop-related tasks and dashboards.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Tailwind CSS, Shadcn-ui
- **Database**: PostgreSQL (default SQLite for development)
- **Authentication**: JWT-based authentication using passlib for password hashing

# Usage
1. **Install Dependencies**:
   - For the backend, navigate to the `/backend` directory and run `pip install -r requirements.txt`.
   - For the frontend, navigate to the `/frontend` directory and run `pnpm install`.
   
2. **Build**: 
   - For the frontend, run `pnpm run build` to create a production build.
   
3. **Run**:
   - Start the backend service by executing `uvicorn main:app --reload` in the backend directory.
   - Start the frontend development server by running `pnpm run dev` in the frontend directory.

4. **Database Migration**:
   - To remove outdated planning records, execute the SQL script located at `/workspace/delete_old_plannings.sql` using your preferred database client.
