## Source 1 — Kaggle Dataset (External) ✅ Already Downloaded

**File:** `ai4i2020.csv` (located in project root)
**Origin:** [AI4I 2020 Predictive Maintenance Dataset](https://www.kaggle.com/datasets/stephanmatzka/predictive-maintenance-dataset-ai4i-2020)

### What it contains
| Column | Type | Description |
|---|---|---|
| `Air temperature [K]` | Float | Ambient temperature around the machine |
| `Process temperature [K]` | Float | Machine operating temperature |
| `Rotational speed [rpm]` | Integer | Motor rotation speed |
| `Torque [Nm]` | Float | Mechanical torque applied |
| `Tool wear [min]` | Integer | Cumulative tool usage time |
| `Machine failure` | Binary | **Target** — 0 = Healthy, 1 = Failed |
| `TWF` | Binary | Tool Wear Failure sub-label |
| `HDF` | Binary | Heat Dissipation Failure sub-label |
| `PWF` | Binary | Power Failure sub-label |
| `OSF` | Binary | Overstrain Failure sub-label |
| `RNF` | Binary | Random Failure sub-label |

### Key Stats
- **Total rows:** 10,000 machines × time steps
- **Failure rate:** ~3.39% (highly imbalanced — handled with SMOTE)
- **No missing values** — clean dataset, ready to use

## Source 2 — Internal PostgreSQL Database (Our Own Data)

This is real operational data generated by the EAM platform itself as technicians use it.

### Tables Available for ML
you can fetch the data from the database using docker and postgresql queries:

| Table | Useful Columns | ML Use Case |
|---|---|---|
| `machines` | `status`, `type`, `zone`, `created_at` | Feature engineering (machine age, type) |
| `interventions` | `date`, `duration`, `machine_id`, `type` | RUL estimation, MTBF/MTTR computation |
| `work_orders` | `priority`, `created_at`, `status`, `machine_id` | Work order priority prediction |
| `plannings` | `zone`, `sous_zone`, `ordre`, `date` | Maintenance schedule optimization |

### How to Extract This Data
you can fetch the data from the database using docker and postgresql queries:
```python
import pandas as pd
from sqlalchemy import create_engine

engine = create_engine("postgresql://user:password@localhost:5432/eam_db")

# Example: load all interventions
interventions_df = pd.read_sql("SELECT * FROM interventions", engine)

# Example: load machines with their work order counts
query = """
    SELECT m.id, m.status, m.type, COUNT(wo.id) AS work_order_count
    FROM machines m
    LEFT JOIN work_orders wo ON wo.machine_id = m.id
    GROUP BY m.id
"""
machines_df = pd.read_sql(query, engine)
```

> ⚠️ Check your `.env` file for the correct `DATABASE_URL` connection string.
