**Data fetching — loadData() called on mount + every 30s:**
```typescript
const API = import.meta.env.VITE_API_BASE_URL || '';
const getToken = () => localStorage.getItem('access_token');

// 1. Fetch alerts
const alertsRes = await fetch(`${API}/api/v1/alerts`, {
  headers: { Authorization: `Bearer ${getToken()}` }
});
const alertsData = await alertsRes.json();
setAlerts(alertsData);

// 2. Fetch machines (for name map)
const machinesRes = await client.entities.machines.query({ query: {}, limit: 500 });
const map = new Map<number, string>();
for (const m of machinesRes.data?.items || []) {
  map.set(m.id, m.nom || `Machine #${m.id}`);
}
setMachinesMap(map);

// 3. Fetch technicians
const techRes = await fetch(`${API}/api/v1/cheftech/techniciens?page=1&size=100`, {
  headers: { Authorization: `Bearer ${getToken()}` }
});
const techData = await techRes.json();
setTechnicians(techData.items || []);
```

Set up 30s polling interval via setInterval in useEffect, clear on unmount.
