<task type="auto">
  <name>Task 1: Create Alert Service and Database Model</name>
  <files>app/backend/services/alertes.py</files>
  <action>
Create `Alert` model in database:
- id (UUID, primary key)
- machine_id (FK to machines)
- alert_type: enum (RUL_WARNING, FAILURE_PREDICTED, ANOMALY_DETECTED)
- severity: enum (LOW, MEDIUM, HIGH, CRITICAL)
- message (text)
- rul_days (float, nullable - from P3 prediction)
- failure_probability (float, nullable - from P1 prediction)
- is_active (bool, default true)
- created_at (datetime)
- dismissed_at (datetime, nullable)
- dismissed_by (FK to utilisateurs, nullable)

Create `alertes.py` service with:
- `create_alert(machine_id, alert_type, severity, message, rul_days=None, failure_probability=None)` - creates alert
- `get_active_alerts()` - returns list of active alerts
- `dismiss_alert(alert_id, user_id)` - marks alert as dismissed
- `check_and_create_alerts()` - runs ML predictions, creates alerts for machines where RUL < threshold
  </action>

<task type="auto">
  <name>Task 5: Integrate Alert Generation with ML Predictions</name>
  <files>app/backend/services/alertes.py</files>
  <action>
Update `check_and_create_alerts()` to:
1. Fetch all machines
2. Call ML prediction API for each (or batch endpoint)
3. For each machine where P3.rul_days < config.threshold:
   - Create RUL_WARNING alert
4. For each machine where P1.failure_probability > 0.7:
   - Create FAILURE_PREDICTED alert (HIGH severity)
5. For each machine where P4.is_anomaly == true:
   - Create ANOMALY_DETECTED alert

Create Celery periodic task to run `check_and_create_alerts()` every hour.
  </action>
