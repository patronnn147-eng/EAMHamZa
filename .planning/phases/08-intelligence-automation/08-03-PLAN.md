<task type="auto">
  <name>Task 1: Create Chat Query Parser Service</name>
  <files>app/backend/services/chat.py</files>
  <action>
Create chat service with keyword-based query parser:

Intent Classification (simple keyword matching):
- "which machines in {zone}" → list machines by zone
- "due for maintenance" → machines with upcoming maintenance
- "show alerts" → active alerts
- "critical machines" → high-severity alerts or P1 > 0.7
- "work orders for {technician}" → work orders by assignee
- "machines needing repair" → machines in breakdown status
- "expensive repairs" → work orders with high cost
- "predictive maintenance" → machines with low RUL

Query Parser:
- `parse_query(user_input: str)` → returns intent + parameters
- `execute_query(intent: str, params: dict)` → calls appropriate service
- `format_response(results, intent)` → formats for display

Supported intents:
- list_machines (by zone, status, type)
- show_alerts (by severity)
- show_work_orders (by status, assignee, priority)
- show_predictions (critical/failure predicted)
- show_costs (maintenance costs)
  </action>

  </verify>
  <done>Query parser correctly identifies intents</done>
</task>
