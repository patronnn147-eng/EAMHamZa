# Plan 12.1-03: Chat Integration + Upload API (Proxy Architecture)

## Objective

Wire RAG retrieval into existing chat endpoints via httpx proxy to rag-service.
Build document management API that proxies to rag-service.
NO embedding or pgvector in main backend — all ML work isolated to rag-service container.

## Architecture

```
Frontend → POST /api/v1/rag/documents (main backend)
              → httpx POST rag-service:8003/ingest
                  → extract → chunk → embed → pgvector

Frontend → POST /api/v1/chat/ai/chat (main backend)
              → rag_client.retrieve_chunks()
              → httpx POST rag-service:8003/retrieve
              → build_full_system_prompt(rag_chunks=chunks)
              → Groq LLM call
```

## Tasks

### Task 1: Create services/rag_client.py

Thin httpx async wrapper with 4 functions:
- `retrieve_chunks(query, machine_id?, top_k, threshold)` → list[dict] — degrades to [] on error
- `ingest_document(file_bytes, filename, doc_type, machine_id?, uploaded_by?, description?)` → dict
- `list_documents(doc_type?, machine_id?)` → list[dict]
- `delete_document(doc_id)` → None

RAG_SERVICE_URL from env (default: http://rag-service:8003).

### Task 2: Update services/ai_prompts.py

Add `build_rag_context(chunks)` — formats as [CONTEXTE DOCUMENTAIRE] section.
Update `build_full_system_prompt()` signature to accept `rag_chunks: Optional[List[Any]] = None`.

### Task 3: Update schemas/ai_chat.py

Add to `ChatRequest`:
```python
machine_id: Optional[int] = Field(
    default=None,
    description="Optional machine ID for filtered RAG retrieval",
)
```

### Task 4: Update modules/shared/routes/chat.py

In `ai_chat()`, insert RAG retrieval BEFORE system prompt build:
```python
# ── 2. RAG retrieval ─────────────────────────────────────────────────
rag_chunks = []
try:
    rag_chunks = await rag_client.retrieve_chunks(
        query=request.message,
        machine_id=getattr(request, "machine_id", None),
        top_k=3,
        threshold=0.7,
    )
except Exception as e:
    logger.warning(f"RAG retrieval failed, continuing without context: {e}")
```

Change system prompt build to:
```python
system_prompt = build_full_system_prompt(role_name, user_name, memories, rag_chunks)
```

In `analyze()`, add RAG retrieval using `request.query`, append context to query string.

### Task 5: Create modules/shared/routes/rag_docs.py

Proxy router (`prefix="/api/v1/rag"`) with 3 endpoints:
- `POST /documents` — validates file, reads bytes, calls rag_client.ingest_document()
- `GET /documents` — calls rag_client.list_documents()
- `DELETE /documents/{id}` — calls rag_client.delete_document()

Auth via `get_current_user` on all endpoints.
Error handling: ConnectError → 503, HTTPStatusError → forward status code.

Router auto-discovered — no changes needed to main.py.
