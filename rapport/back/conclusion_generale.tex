\chapter*{General Conclusion}
\addcontentsline{toc}{chapter}{General Conclusion}

This end-of-studies project made it possible to design and implement an asset management and predictive maintenance platform for industrial equipment, addressing the problem stated in the introduction: unifying, within a single system, traditional operational asset management, machine-learning-based failure prediction capabilities, and intelligent support for maintenance teams.

The approach followed \textemdash{} requirements analysis, design of a modular architecture, iterative implementation, then validation through testing \textemdash{} made it possible to deliver a coherent system in which each Machine Learning module (P1 to P7) is seamlessly integrated into the day-to-day management of work and intervention orders, with systematic explainability to remain accessible to non-specialist users.

On the technical side, this internship deepened my understanding of microservices architecture design, the application of Machine Learning techniques to concrete industrial problems (classification, regression on survival data, anomaly detection, fusion of multiple sources of evidence), as well as the implementation of Retrieval-Augmented Generation (RAG) systems. On a personal level, this internship strengthened my autonomy in running a project end to end, my ability to document and justify technical choices, and my rigor in systematically validating each component before integrating it.

Several avenues for improvement emerge from this work: extending the RAG service to new document formats, training the models on real production data rather than simulated data, and strengthening human oversight in the automation of spare parts provisioning.
