\section{Selected code excerpts}

The excerpt below illustrates, in simplified form, the score fusion logic of the anomaly detection ensemble (P4 module), with weight renormalization when a detector is unavailable:

\begin{verbatim}
def fuse_anomaly_scores(scores: dict, weights: dict) -> float:
    available = {k: v for k, v in scores.items() if v is not None}
    total_weight = sum(weights[k] for k in available)
    if total_weight == 0:
        return 0.0
    return sum(scores[k] * weights[k] for k in available) / total_weight
\end{verbatim}

The following excerpt illustrates the principle behind computing the operational readiness score (P7 module), combining several weighted signals:

\begin{verbatim}
def compute_readiness_score(health, inventory, shortage, recency):
    return (
        0.40 * health
        + 0.30 * inventory
        - 0.20 * shortage
        + 0.10 * recency
    )
\end{verbatim}
